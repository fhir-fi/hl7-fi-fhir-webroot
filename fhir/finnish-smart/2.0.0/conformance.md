## Conformance

### Capability Statement

The [Finnish SMART Server Capability Statement](CapabilityStatement-fi-smart-server.md) definition includes formal requirements for SMART servers in Finland.

In essence, it mandates support for REST API's and for JSON format, and recommends support for the IPA specification and for XML format.

The [Finnish SMART Server Capability Statement Profile](StructureDefinition-fi-smart-server-profile.md) is intended to help in validation of server capability statements.
